# Biblioteca interactiva para API de libros

Mini app web (HTML/CSS/JS) para conectarse a una API de libros usando `x-api-key` y `x-api-secret`.

## Funcionalidades

- Formulario para URL base + endpoint de libros.
- Botón para conectar y cargar libros.
- Búsqueda en tiempo real por título, autor o categoría.
- Orden por título, autor y año.
- Mostrar/ocultar secret.
- Limpieza de resultados.

## Ejecución local

```bash
python3 -m http.server 8000
```

Abre `http://localhost:8000`.
